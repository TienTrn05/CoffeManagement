**Coffee Shop Management — Desktop Application**

GitHub: https://github.com/TienTrn05/CoffeManagement

**Technologies:** C#, .NET Framework 4.7.2, WinForms, Entity Framework 6, SQL Server, LINQ, Guna UI2

- Developed a Windows desktop application for coffee shop operations, including table management, ordering, and discounted checkout.
- Implemented CRUD operations for drinks, categories, tables, and user accounts, with admin/staff access and profile management.
- Integrated SQL Server using Entity Framework Database First and LINQ to manage orders, bill details, and invoice records.
- Separated Windows Forms screens from business logic and added event-driven refreshes after menu and table updates.

## Short version

Built a C# WinForms coffee shop management application with table-based ordering, discounted checkout, menu and account management, and admin/staff access. Integrated SQL Server through Entity Framework and LINQ, with separate UI and business logic layers.
